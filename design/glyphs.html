Six worked properly, in the visual language you picked. The rule the set follows: the jamo's own strokes are the drawing's load bearing structure, always at full weight in the foreground. The gold linework only ever adds context around them, and it is never allowed to become part of a stroke or to close a shape the jamo leaves open.

Flip Context art to hidden. That is the real test. Every glyph should collapse to a clean, correctly proportioned jamo with nothing missing and nothing extra. If one only reads as a picture because of the gold, it fails, and I'd redraw it.

Each mnemonic is picked shape first. The question is never "what starts with g", it is "what is already this shape, and does its name start with the sound". A gutter and a goose are both shaped like ㄱ; only one of them is worth drawing. So: ㄱ goose, ㄴ nose, ㄷ door, ㄹ river, ㅁ mouth, ㅂ bucket.
